Open-Source Licenses

Last updated: November 18, 2026

EZDL is built on great open-source software. Each project below is a separate program or library distributed under its own license. A copy of these notices and the license texts ships with the app, in the resources\licenses folder inside the EZDL install folder.

FFmpeg

FFmpeg does EZDL's video and audio processing: converting, compressing, clipping, merging, and more. EZDL runs FFmpeg as a separate program (ffmpeg.exe and ffprobe.exe); FFmpeg's code is not part of EZDL's own code.

  • ffmpeg.exe: version 6.1.1, essentials build by gyan.dev. Source code: FFmpeg commit e38092ef93.
  • ffprobe.exe: version 4.0.2. Source code: FFmpeg n4.0.2.
  • License: GNU General Public License v3.
  • Project: ffmpeg.org

Written offer: for at least three years from the date you received EZDL, we will provide the complete corresponding source code for these GPL-licensed programs on request, at no charge beyond the cost of shipping. Email support@ezdl.net.

yt-dlp

yt-dlp handles downloading from websites. EZDL runs it as a separate program (yt-dlp.exe) and keeps it up to date automatically.

  • License: The Unlicense (public domain)
  • Project: github.com/yt-dlp/yt-dlp

Electron and Chromium

EZDL's app window is built with Electron, which includes Chromium and Node.js.

  • Electron: MIT License
  • Chromium and its components: BSD-style and other open-source licenses, listed in LICENSES.chromium.html in the EZDL install folder.
  • Project: electronjs.org

Thank you

Thanks to everyone who builds and maintains these projects. EZDL wouldn't exist without them. Questions about licensing? Email support@ezdl.net.
